KEUANGANKU PWA
Cara memakai di iPhone:
1. Upload folder ini ke layanan hosting statis yang mendukung HTTPS (mis. GitHub Pages, Netlify, atau Cloudflare Pages).
2. Buka URL-nya di Safari iPhone.
3. Tekan Share -> Add to Home Screen.
4. Buka KeuanganKu dari Home Screen.
Data transaksi tersimpan di browser/perangkat melalui localStorage.
